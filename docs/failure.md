# 付款失败的七种原因与排查顺序

按出现频率排序。先看提示语，再对症。

## 1. `Your card has been declined`

**原因**：发卡地区或号段被拒，或余额不足以覆盖预授权。

**排查**：

```
确认卡是海外 BIN（不是国内卡走海外通道）
余额比订阅价多留 2-3 美元
换号段重试，不要在同一张卡上反复试
```

## 2. `We are unable to authenticate your payment method`

**原因**：账单地址与付款时的网络地区不一致，触发了 3D 验证。

**排查**：

```
账单国家 = 卡的发行国 = 你当前出口 IP 的国家
三项必须一致
```

## 3. 页面一直转圈 / 提交后无响应

**原因**：Stripe 的请求被网络层拦截（常见于代理不稳定）。

**排查**：换一个稳定出口，用浏览器无痕模式重试。

## 4. 提示已扣款但订阅没生效

**原因**：预授权成功，正式扣款失败；或订阅绑到了别的账号。

**排查**：等 10 分钟刷新；确认登录的是哪个邮箱；查银行/平台的交易记录。

## 5. 开通几天后被取消

**原因**：OpenAI 二次风控判定支付来源异常。

**排查**：这类基本无法申诉。改用直充或自己能控制的支付方式。

## 6. 账号被停用（deactivated）

**原因**：支付异常 + 异地登录 + 多设备并发，三者叠加最容易触发。

**排查**：走官方申诉，成功率取决于能否提供注册信息与支付凭证。买来的号通常拿不出来。

## 7. 代充后掉档

**原因**：代充方用的是试用/黑卡，到期不续或被发现。

**排查**：找代充方要续费；长期看还是要自己的支付方式。

---

## 通用排查顺序

```
1. 提示语抄下来，对照上面七条
2. 检查三件事：卡国家 / 账单国家 / IP 国家
3. 检查余额（留足预授权）
4. 换号段或换平台
5. 仍失败 → 放弃这条支付路径，换路线
```

**最没用的事**：反复点付款。多次失败会触发风控，卡被冻结，后面换什么都没用。
