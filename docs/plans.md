# Plus / Pro 5x / 20x / 50x 到底差在哪

OpenAI 现在的个人订阅分几档，名字里的 5x / 20x / 50x 指的是**用量倍数**，不是速度，也不是功能。

## 先分清两件事

```
Plus        单档，价格最低，日常够用
Pro         分 5x / 20x / 50x，倍数越高，可用的推理额度越多
```

## 倍数意味着什么

| 档位 | 适合谁 | 什么时候会觉得不够 |
|---|---|---|
| Plus | 日常问答、写作、轻度代码 | 连续几小时高强度用、频繁长文档 |
| Pro 5x | 每天固定用几小时、写代码 | 多项目并行、长时间 agent 任务 |
| Pro 20x | 全职使用、重度代码 | 极少，除非团队共用一个号 |
| Pro 50x | 多人协作或自动化流水线 | 基本不会 |

**判断方法**：看你会不会撞到"额度用尽，X 小时后恢复"的提示。一周撞三次以上，才值得往上加一档。

## 常见误解

**1. 倍数不是速度**

50x 不会让回答变快，只让你能用更久。

**2. 倍数不叠加功能**

所有档位能用到的模型是一样的，区别在配额。新功能通常先给所有付费用户，不分档。

**3. 贵的那档不一定更划算**

如果你一周只用十几次，Pro 的额度大部分是浪费的。Plus 加一个 API 按量付费，往往比 Pro 更省。

## 怎么选

```
偶尔用             Plus
每天固定用 1-2 小时  Plus 或 5x
全职写代码/长时间跑  20x
团队或自动化        50x
```

买之前先想清楚：**你上一次撞到额度限制是什么时候？** 想不起来的，Plus 就够。

## 续费提醒

高倍档按年订阅更便宜，但退款政策严格。不确定能不能长期用时，先按月。
