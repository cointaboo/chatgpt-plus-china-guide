## 三个必须先搞清楚的事实

### 1. OpenAI 只认海外发行的卡

国内银联卡、支付宝、微信在 Stripe 结账页一律失败，提示 `Your card has been declined`。这不是余额问题，是发卡地区问题。

### 2. 订阅成功 ≠ 账号安全

用虚拟卡或代充开通后，OpenAI 还会做二次风控。支付来源被判定异常时，订阅会被取消，严重的会连带封号。

### 3. 便宜的价格通常对应某种风险

低于市场价很多的报价，通常是：共享账号、盗刷卡、或者随时会被找回的号。这三种都会在你用了一段时间之后出问题。

## 怎么用这份指南

先读 `docs/routes.md` 确定路线，再按对应文件操作。付款失败的看 `docs/failure.md`，选档位的看 `docs/plans.md`。

内容基于实际使用与踩坑记录整理，不构成购买建议。订阅类服务的风控规则会变，以你操作当时的页面提示为准。
